CSV Format Requirements

The CSV file must have the following columns (in order):

  • Date - Format: YYYY-MM-DD (e.g., 2025-01-15)
  • Type - Either "Income" or "Expense"
  • Category - Category name (must exist in your categories)
  • Account - Account name (must exist in your accounts)
  • Amount - Numeric value (e.g., 100.50)
  • Description - Optional transaction description
  • Notes - Optional transaction notes
Example CSV:
Date,Type,Category,Account,Amount,Description,Notes
2025-01-15,Expense,Groceries,Main Account,150.00,Weekly shopping,
2025-01-16,Income,Salary,Main Account,5000.00,Monthly salary,
